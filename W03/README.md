# 2026 年 10 月课件

本目录存放 UFCFAF-30-3（Development of Information Systems Projects）的课件和 i\* 画图工具 piStar。这些幻灯片没有印周次。

| 文件 | 内容 |
|------|------|
| `BPMN Strategic Process Models.pptx` | David Wyatt 讲战略级 BPMN。模型从触发画到结果，主要画顺利路径，放在一张纸上，大约不超过 10 个流程对象。分叉用互斥网关，汇合处不画互斥网关。并行用与网关。不用或网关，也不用复杂网关。细节放进子流程。 |
| `Process Orchestration.pptx` | David Wyatt 讲流程编排。编排器协调人、系统和设备，包括动态并行、消息关联和超时升级。Camunda 在这里是编排器。 |
| `Application Architectures and Distribution.pptx` | David Wyatt 讲应用架构与分布式。内容包括企业应用、仓储、客户端-服务器、管道与过滤器、分层、中间件、基于消息的集成，以及强一致与最终一致。 |
| `SOAP Based Web Services.pptx` | David Wyatt 讲 SOAP。内容包括面向服务的架构、SOAP 消息、WSDL、UDDI，以及单体、面向服务和微服务的差别。 |
| `RESTful Web Services.pptx` | David Wyatt 讲 REST。内容包括 HTTP 方法、REST 原则、用 URI 命名资源，以及 REST 和 SOAP 的对照。 |
| `Goal-Oriented Strategic Modelling.pptx` | Franglin 用 i\* 讲面向目标的战略建模，包括战略依赖图和战略理由图。 |
| `Additional iStar-Presentation.pptx` | David Wyatt 讲 i\* 的第二部分：参与者及其联系、建模视图、意图元素、社会依赖。课堂例子是大学差旅报销。 |
| `HCI.pptx` | Franglin 讲人机交互。内容包括用户、人物志、十条可用性规则、无障碍、线框原型和可用性测试。 |

`piStar/` 是 i\* 画图工具。`piStar.zip` 是同一工具的压缩包。
