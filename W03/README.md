# 2026 年 10 月课件

这些幻灯片和 piStar 放在本仓库，接在 `W01/`、`W02/` 后面。课程代码是 UFCFAF-30-3，课程名称是 Development of Information Systems Projects。9 月已经提交的医院路径作业仍在本仓库的 `docs/`、`Coursework/` 和 `submissions/`。

幻灯片本身没有印周次。微信原件文件名末尾的 `(DW)`、`(1)`、`(2)` 已去掉，每种只留一份。

| 文件 | 内容 |
|------|------|
| `BPMN Strategic Process Models.pptx` | David Wyatt，文件修改时间 2026-10-07。战略级 BPMN：从触发画到结果，主要画顺利路径；一张纸、大约不超过 10 个流程对象；分叉用互斥网关，汇合不再画互斥网关；并行用与网关；不用或网关和复杂网关；细节放进子流程。 |
| `Process Orchestration.pptx` | David Wyatt，文件修改时间 2026-10-07。流程编排：编排器协调人、系统和设备；动态并行、消息关联、超时升级。Camunda 在这里是编排器。 |
| `Application Architectures and Distribution.pptx` | David Wyatt，封面写 10 月 26 日。企业应用、仓储、客户端-服务器、管道与过滤器、分层、中间件、基于消息的集成，以及强一致与最终一致。 |
| `SOAP Based Web Services.pptx` | David Wyatt。面向服务的架构、SOAP 消息、WSDL、UDDI，以及单体、面向服务和微服务的差别。 |
| `RESTful Web Services.pptx` | David Wyatt。HTTP 方法、REST 原则、用 URI 命名资源，以及 REST 和 SOAP 的对照。 |
| `Goal-Oriented Strategic Modelling.pptx` | Franglin，文件修改时间 2026-10-11。用 i\* 做面向目标的战略建模，包括战略依赖图和战略理由图。 |
| `Additional iStar-Presentation.pptx` | David Wyatt，文件修改时间 2026-10-11。i\* 第二部分：参与者及其联系、建模视图、意图元素、社会依赖，课堂例子是大学差旅报销。 |
| `HCI.pptx` | Franglin，高级信息系统开发中的人机交互。用户、人物志、十条可用性规则、无障碍、线框原型和可用性测试。课下作业是：请一位朋友试用一个应用十分钟，写出三个问题，并用十条可用性规则写出三处修改；保留人物志和草图。 |

`piStar.zip` 是 i\* 画图工具 piStar 的源码包，已解压到 `piStar/`。压缩包保留，作为收到的原件。
