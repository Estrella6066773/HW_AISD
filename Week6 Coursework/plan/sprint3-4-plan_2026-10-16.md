## What this plan deliberately does not include

- No new scope. The second release is marked on improvements and on the evaluation, not on adding case functions that were never in the first release.
- No claim that any unreceived feedback has been actioned.
- No third set of task IDs. Every row is a backlog item, so a row's ID and the backlog entry are the same `PB` number.
